# 리팩토링 운영 반영 체크리스트

체크된 항목만 수행 완료다. 나머지는 **미완료**이며 수행자·날짜·대상 환경·결과를 별도 기록한 뒤 체크한다. 자동 테스트 통과로 실제 서버 검수를 대체하지 않는다.

## 1. 배포 판단 전

- [x] 앱/웹 오류 카탈로그 차이를 검토하고 `npm run verify:refactor` 전체 통과 확인 (2026-11-26, 로컬 자동 점검: 지정 테스트 1,070개·타입·lint 오류 없음·로컬 빌드 성공. 배포 직전 재실행 필요)
- [ ] 변경·삭제·미추적 파일 전체 리뷰. 파일 이동 누락 및 관련 없는 변경 제외
- [ ] 별도 DB/가상 데이터 환경 확인. 실제 푸시·문자·결제·환불은 서버에서도 차단한 후 검수
- [ ] 운영 RPC·Edge 버전/권한과 이번 클라이언트 호출 계약 대조. 필요 SQL은 별도 리뷰·승인
- [ ] 수업 삭제 CASCADE, 결제 취소 서버, 출결 원자성/복원 정책의 미해결 위험을 해소하거나 해당 작업을 명시적으로 차단
- [ ] 배포 담당자, 장애 대응 담당자, 이전 배포 복귀 절차 확보

## 2. 실제 웹 검수 — 중요도순

| 순서 | 업무 | 확인할 시나리오 |
| --- | --- | --- |
| 1 | 청구·수납 | 웹/앱 청구 구분과 실제 청구 ID, 월·지점 조회, 금액, 중복 클릭, 미확인 응답 후 재조회, 저장 성공/알림 실패 구분 |
| 2 | 취소 | 격리된 모의 PG/서버에서 허용·차단 대상 확인. 실제 돈으로 시험하지 않음. DB 직접 갱신 우회 없음 |
| 3 | 학생 | 검색·페이지, 상세 편집·지점 전환·탈퇴, Excel 검증·부분 저장 후 복구 안내 |
| 4 | 학습·상담 | 조회·작성·수정·삭제·파일, 권한 거부, 저장 후 알림 실패, 화면 이동 중 늦은 응답 |
| 5 | 출결 | 수동·일괄·키패드/앱 연계, 중복 처리·부분 성공·취소 복원, 가로 스크롤·출석 횟수·페이지 이동 |
| 6 | 수업·시간표 | 등록·수정·예약, 지점/강사 범위, 겹침·오류. 삭제는 정책 확인 전 실행 금지 |
| 7 | 공지·설정 | 일반/본사 구분, 저장·삭제·선택적 모의 푸시, 설정·영상·협력사 변경 후 새로고침 |
| 8 | 기타/공통 | 대시보드·추천·지도·강사·문자·권한 화면, 모바일/축소 화면, 키보드 조작·로딩·빈 목록·재로그인 |

- [ ] admin·원장·선생 등 실제 역할별 허용 범위 확인
- [ ] 다른 지점/일반 사용자/비로그인의 읽기·쓰기 거부를 **서버에서** 확인 (UI 숨김만 확인하지 않음)
- [ ] 세션 만료·연결 끊김·더블클릭·저장 중 지점/화면 변경에서 데이터 혼선이나 반복 발송 없음
- [ ] 개인정보·토큰·결제 인증값이 화면/콘솔/서버 로그에 노출되지 않음

## 3. 배포 및 배포 후

- [ ] 변경 전 백업/복구 가능 여부 확인. 프론트 복귀는 이미 저장된 DB 변경을 되돌리지 않음을 공유
- [ ] 승인된 대상 브랜치·커밋·환경 변수·공개 키 종류 확인. 비밀 키를 프론트에 넣지 않음
- [ ] 운영 빌드 산출물 별도 생성. `dist-local` 또는 테스트용 공개 설정 산출물 배포 금지
- [ ] 소규모 승인된 계정으로 로그인·읽기 중심 스모크 검수 후 확대
- [ ] 오류율·업무 문의 모니터링, 중복 청구/발송/권한 이상 시 중단·복귀 및 상태 대조

현재 자동 검증 현황과 미해결 항목은 [인수인계 문서](refactor-handoff.md)를 기준으로 본다. 이 문서는 배포 또는 운영 DB 변경을 승인하는 문서가 아니다.
