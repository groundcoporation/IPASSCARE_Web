# 결제 취소 경로 보완 및 남은 검토

## 이번 웹 수정

- `pages/admin/billing/model/paymentCancellation.ts`: 금액·상태·수단·거래번호와 전체취소 가능 범위를 검사한다.
- `pages/admin/billing/api/paymentCancellation.ts`: 카드 Edge 또는 현장결제 RPC만 호출한다. 클라이언트에 `payments`/`user_packages` 수정·삭제 경로가 없다.
- PG 실패·응답 유실·불명확한 응답은 성공으로 표시하지 않는다. 자동 재시도하지 않으며 원거래와 기존 내역 확인을 안내한다.
- 성공은 명시적인 `success: true`, 허용 승인 코드, 전체취소 유형, 요청 금액 일치로 확인한다. 현장결제는 기존 취소/이미 취소 응답을 검사한다. 서버가 거래 ID를 반환하면 같은 ID인지도 확인한다.
- 성공 전 낙관적 `cancelled` 상태 반영을 제거했다. 서버 응답 뒤 목록을 재조회하며 조회 실패는 별도 안내한다. 중복 클릭·다른 취소창 열기·처리 중 닫기/입력 변경을 차단한다.
- 지점·결제 월·탭 변경 후 이전 응답은 새 취소창을 닫거나 이전 목록을 재조회하지 않는다. 오래된 결제 조회 응답도 최신 목록을 덮어쓰지 않는다.
- 조회 응답의 일부 관계 오류를 무시하지 않고 전체 조회 실패로 다룬다. 원시 오류를 화면/로그에 내보내지 않는다.

## 현재 지원 범위

| 대상 | 웹 처리 |
| --- | --- |
| 거래번호가 있는 완료된 CARD 결제, 기취소 금액 없음, 원금 전체 | 기존 `kspay-cancel`에 전체취소 요청 |
| 현금·현장 카드·현장 이체의 완료/예정 건, 원금 전체 | 기존 `cancel_offline_payment` RPC. 실제 환불 별도 확인 |
| 부분취소 또는 이전 환불 이력이 있는 거래 | 서버 정책 확인 전 차단 |
| 온라인 거래번호 없음·가상계좌·포인트·미지원 수단 | 임의 DB 취소 없이 차단 |
| 비정상 금액·이미 취소/실패한 원거래 | 요청 전 차단 |

환불 금액은 기존 로드된 거래 이력으로 계산하므로 전체 서버 이력이나 동시 요청을 보장하지 않는다. 클라이언트 차단만으로 다른 앱·기기의 요청까지 차단되는 것은 아니다.

## 운영 반영 전 서버 검토 필요

검토 근거는 로컬 앱 저장소의 `supabase/functions/kspay-cancel/index.ts`다. 운영에 같은 버전이 배포되어 있는지는 확인하지 않았다. 이번에는 서버 함수·SQL·운영 데이터를 수정하지 않았다.

1. 부분취소에서도 연결 이용권 전체를 삭제하는 경로가 있다. 회수 수량·유효 이용권·청구 상태의 부분취소 정책이 정해지고 검증되기 전 웹에서 요청하지 않는다.
2. PG 승인 후 DB 여러 단계는 하나의 트랜잭션이 아니다. 일부 요청 오류를 무시하거나 경고만 남기는 경로가 있어 서버의 성공 응답만으로 모든 이용권/청구 동기화를 보장하지 않는다.
3. 승인 후 DB 실패나 응답 유실은 PG 실패가 아니다. 같은 취소를 재시도하기 전에 PG 거래 상태와 DB 반영 단계를 조회/복구할 계약이 필요하다.
4. 서버의 누적 취소 금액 검증·동시 요청 잠금·멱등성 키/취소 작업 이력·재조정 절차가 필요하다. 프론트 잠금만으로 중복 취소를 보장할 수 없다.
5. 거래 응답/원시 오류 로그의 허용 필드와 정보 노출 범위를 점검해야 한다. 이번 웹 오류 정리는 서버 로그를 정리한 것이 아니다.
6. 현장 장부 취소는 현금 반환이나 PG 환불 실행이 아니다. 별도 실제 환불 절차와 증빙 확인이 필요하다.

운영 반영 완료 또는 결제 시스템 전체 안전성 검증 완료 문서가 아니다. 서버 작업은 앱 저장소의 별도 작업 브랜치·검토·격리 테스트와 배포 승인을 거쳐야 한다.

## 검증

- `npm run test:payment-cancel`: 실제 네트워크 없이 성공/거절/권한/응답 유실/부분취소 차단/현장 RPC/중복 클릭/오래된 화면/조회 실패를 검증한다.
- 실제 PG 취소·실제 현장 취소·DB 수정·이용권 회수·운영 배포는 실행하지 않았다. 카드사/서버/RLS·브라우저 검수는 별도로 필요하다.
